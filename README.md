# BooksHaven

BooksHaven is a web-based library management system designed to simplify and modernize the process of managing books and borrowing activities in a library. The platform allows students to browse the book catalogue, view book details, and borrow or return books, while administrators can manage books, users, and borrowing records through an admin dashboard.

The system aims to replace manual and fragmented library processes by providing a centralized digital platform that improves efficiency, transparency, and accessibility. It also integrates external book metadata to enrich the catalogue and provide better information for users.

Features

User authentication (login and registration)

Browse and search the library catalogue

View detailed information about books

Borrow and return books

View current borrowings

Admin panel to manage books and users

Borrowing history tracking

Tech Stack

Frontend: React + Vite

Backend: Django + Django REST Framework

Database: SQLite / PostgreSQL

External API: Google Books API

BooksHaven was developed as a university project to demonstrate full-stack web development, database design, RESTful APIs, and accessible user interface design following WCAG 2.2 guidelines.
